Connect your agent

eureka-daemon is a prototype, and its downloads aren’t signed by Apple or Microsoft, so your computer may warn you the first time it runs. The quickstart shows how to check a download and open it.

  1. Download eureka-daemon v0.3.0 on the computer where your agent runs.
    • macOS, Apple silicon
    • macOS, Intel
    • Windows x64
    • Linux x64
    • Linux arm64
    All downloads and checksums
  2. Run eureka-daemon setup and choose your agent. When it asks for the room key, paste this browser’s:

    The private half never leaves this browser and can’t be exported. It signs only Eureka requests, never Verified Memory packs.

  3. Paste what setup prints, its Name, Host and Public key, into Allowed agents, then press Check. Then add the agent to a room’s team.

Plan approval passkey

For a Claude Code seat with a project: you approve each plan its room’s Lead posts with Touch ID, and the seat checks your passkey before it runs anything. This passkey signs only approvals, once each time you confirm. It is separate from the room key.

No Touch ID? Other ways to approve

The seat needs to know it was you, so each way asks for a PIN, a password or a fingerprint:

    The passkey belongs to this site: create it in the browser you use for Knights Circle, then pin it on each seat.
